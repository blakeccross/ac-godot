## What does the original system do?

Up to 15 villagers live in town (`animals[]` in save). Each has a species/personality id, home acre/unit, catchphrase, cloth, and **per-player memory** (last speak time, friendship `s8`, saved letter).

**New town** (`mNpc_InitNpcAllInfo`): `now_npc_max = mNpc_LOOKS_NUM` (**6**). `mNpc_DecideLivingNpcMax` shuffles the full NPC id table (`mNpc_MakeRandTable`), then walks it and keeps animals whose grow permission is `mNpc_GROW_STARTER` until **one of each looks** is filled. Homes are a second shuffle of SIGN reserves (`mNpc_SetNpcHome`).

A global **schedule manager** ticks all animals. Looks (personality/species group) select a table of `{type, end_time}` slots. Types:

- `mNPS_SCHED_SLEEP`
- `mNPS_SCHED_IN_HOUSE`
- `mNPS_SCHED_FIELD` (home acre)
- `STAND` / `WANDER` / `WALK_WANDER`
- `SPECIAL` (unique actor scripts)

The field type is a **step machine**, not a single wander loop: leave house (hidden) → wander. If they are already outside (`is_home == FALSE`), skip leave and wander immediately. Wander think **does not end** until the schedule type changes (or a pitfall interrupt). Each wander step rolls wait / walk / run from looks weights and walks to a dest on a circle around the **acre center** (`range_radius` 280 GX). That dest is the world point on the circle, not a unit center. Looks change those **odds** (jock run is 50%), not max speed: field `aNPC_spd_data` is walk **1.0** GX/frame and run **3.0** for every personality (shop/special NPCs may force 4.0). 40 GX = 2 m at 30 Hz → **1.5 / 4.5 m/s**. Walk-to-acre / leave / go-home stay on the walk row. Arrival compares dist² to **72 GX** (~0.42 m); a dest more than 90° behind is a turn in place. Motion is continuous along facing (move, then chase turn). Field roam uses **circle** range (`range_radius` 280): dest/avoid must stay inside, and `aNPC_circleRangeRevice` clamps them onto the rim every frame if they leave. Hitting a wall is `aNPC_avoid_obstacle` / `aNPC_avoid_wall` (front+wall with `avoid_direction == 0`: ±112.5° / 1 unit turn-in-place; committed side: 2 units at 22.5° / 45° / 90°, then 180°) — they do not grind a collider. Avoid updates `avoid_pos` only; `dst_pos` stays the rim point. Near the avoid hop, `aNPC_check_arrive_destination` retargets avoid back to `dst_pos` and keeps walking — it does not start a new wander step beside the house. In-house is go home → into house → hide. Sleep hides when `is_home`. While in the field, `m_npc_walk` picks a goal acre from looks-based `{shrine, home, alone, my_home}` tables. Assigned walkers (cap `n/3`) walk toward that acre; everyone else keeps wandering their current acre.

**Talk** is a higher-priority action (`aNPC_ACT_TALK`), not a new schedule type: think yields, they turn to the player, stand until the talk demo ends, then wander resumes. The table can be **forced** for a timer (events). `is_home` on `Animal_c` tracks whether they are inside.

Friendship changes on talk, mail, quests, and annoyances (patience: mildly annoyed / annoyed / normal). Mood (`mNpc_FEEL_*`: normal, happy, angry, sad, sleepy, pitfall) lasts for a `mood_time`. Inter-villager relations are a 15-byte matrix starting at 128 (neutral). Face texture swaps follow mood wait poses: happy → laugh eyes (`eye5`), angry → `eye3` + angry mouth bank, sad → `eye4`, sleepy → shut eyes; normal blinks on `eye0..2`. Frames are `{species}_eye0..7` / `_mouth0..5` from `--kind faces`.

Move-out: `removing`, `remove_animal_idx` on save, minimum days before force removal (`mNpc_MINIMUM_DAYS_BEFORE_FORCE_REMOVAL` 10). Special NPCs use id type `0xD000`.

## Important states

- Roster occupancy vs empty slots.
- Schedule type + forced override.
- Position: in house, home acre, wandering town.
- Friendship per player; last speak time.
- Mood and patience.
- `removing` / last removed id.
- Contest quest slot on the animal.

## Inputs

- Clock (seconds, weekday, season).
- Player talk / mail / gift / hit with net (patience).
- Town events (holidays, tours).
- Save load of `Animal_c` array.

## Outputs / events

- Desired location for the NPC actor (house interior vs field).
- Dialogue personality and available quests.
- Friendship delta.
- Move-in/move-out flags for loading houses and plots.
- “In house” for knocking vs entering.

## Interacts with

- **Time** — schedule tables.
- **World** — home coordinates, field vs room.
- **Player / interaction** — addressable talk.
- **Dialogue** — message ids, catchphrase substitution.
- **Inventory / quests** — deliveries.
- **Furniture** — NPC rooms are a field type with placed FTR.
- **Save** — `animals[]`, `now_npc_max`, `remove_animal_idx`.

## Behavior

- **One villager** with a daily table: sleep, indoors, outdoors, with hour boundaries. Looks (personality) selects the table; the actor is shared.
- New game fills **six** outdoor villagers: shuffle the starter pool, keep one of each looks, assign to the six NPC houses. Each house interior uses that animal’s `npc_house_list` wall/carpet (`VillagerData.wall_index` / `floor_index`). Outdoor shell uses `house_type` / `house_palette` → `obj_s_house{1-5}_{a-e}` (`aHUS_actor_ct`).
- Field day is a reusable action queue: wake / leave home / walk to goal acre / wander / go home / sleep. Wander **loops** for the whole FIELD window (wait / walk / run around the acre). Sit / fish / shop are not the FIELD default.
- While in the field, pick a goal acre from looks+time (`shrine` / other `home` / `alone` / `my_home`). Walkers go there, linger in-acre, then pick a new goal. Concurrent town-walkers cap at `n/3` (max 5). Empty goal-table windows stay on the home acre. Non-walkers still wander their home acre; they do not stand at the door.
- Species GLB (`squ_1`, `cat_1`, …) + shared `npc_1` wait/walk when `assets/generated/characters/villagers/` exists. **Textures are per villager, not per species:** each `npc_draw_data_tbl` entry pairs the species skeleton with its own `tex_data` bank (Stu = `cKF_bs_r_bul_1` + `bul_2_tmem_txt` / `bul_2_pal` / `bul_2_eye*` / `bul_2_mouth*`); all 236 villagers have distinct sets. `VillagerData.texture_set` holds it; `--kind villager-textures` re-walks the model with each other set bound and writes body sheets by GLB material name (`characters/villagers/textures/bul_2/seg_0B_300.png`), `--kind faces` writes `{set}_eye0..` frames, and `VillagerTextures.apply` + `NpcFace.bind(…, texture_set)` swap them in. Check with `tools/capture.sh scene=res://scenes/dev/villager_lineup.tscn ids=stu,angus`. **Size is per draw entry too:** `aNPC_draw_data_c.scale` ranges 0.0055 (mice) to 0.016 (camel) — cubs 0.0065, bulls 0.0125, Nook 0.011. The pipeline bakes it into each NPC GLB as a `{stem}_draw_scale` root node (scale ÷ the flat 0.01 actor scale, so a cub is 0.65×) for every skeleton with a draw entry (`convert._npc_draw_scales`); the game applies the plain actor scale on top, and scenes that instance the GLB show the right size in the editor. A root node rather than a joint scale so `joint_0` root motion scales too. `chn_1` has a second scale only on an unused test villager. Collision radius / height (`col_radius`, `col_height`) are not taken from the draw table yet. Display names use the original villager names. The catalog is every GC animal (`NPC_NUM` 236); new towns still place six (one looks each).
- Talk updates last-spoke and friendship on `Relationship` (not on the dialogue graph). Every catalog villager opens the dialogue overlay: `DialogueGreeting` picks a starting message from looks / meet time / weather / mood, then jumps into the imported bank (or `looks_greeting` if the bank is missing). Talk **interrupts** the current action (`VillagerAI.begin_talk`): they stop, turn toward the player, and hold until the overlay `closed` signal, then resume the previous step (or rebuild if the clock slot changed).
- **Head look** (`ac_npc_head.c_inc`, driven from `aNPC_set_head_angl` as joint 21 draws; `NpcHeadLook`). Target each frame: the talk partner at priority 4 (skips every gate), else the player when xz < 120 GX (6 m) and within ±67.5° of body facing (priority 1). `aNPC_COND_DEMO_SKIP_HEAD_LOOKAT` (asleep in bed `ac_npc_think_sleep`, walking in the door `ac_npc_act_into_house`, …) rejects everything below priority 4; `head.lock_flag` (event minigames only) skips target picking. Angles are measured against the **neck's current world rotation** (`Matrix_to_rotate_new` of the parent joint = YXZ Euler of its world matrix: y is the facing, x the animation's lean): `angle_x = −atan2(eye.y − target_eye.y, dxz) + world.x` — **positive looking up**, clamped only looking **down** at −33.75° — and `angle_y = atan2(target − root) − world.y`, clamped ±67.5°. Target is the player's **eye** (`Actor_world_to_eye(player, 33)` = 1.65 m). Chase rates 0x200 (pitch) / 0x400 (yaw) per 30 Hz frame. No target → chase back to the **animation's own** head angles (`joint_angle`), not zero. Sleepy *feel* freezes the head where it is (`aNPC_check_condition_search_eye`); the sleep activity does not — it just drops the look. The override writes `rot.x = angle_y`, `rot.y = angle_x`, keeps the animation's rot.z; cKF joint rotations are Rz·Ry·Rx, so the bone is decomposed / rebuilt with `EULER_ORDER_ZYX`. Applied on `AnimationPlayer.mixer_applied` (after the mix, like the draw hook). Body does not idle-turn toward the player. NPC eye height is per-species ROM data (not in the decomp source), so the port uses the head bone height. Audit: `scenes/dev/capture_head_look.tscn`. (Before 2026-09-24 the port had pitch inverted, used YXZ on the bone and ignored the neck's lean.)
- **Outdoor interrupts** (`aNPC_think_chk_interrupt_proc`; `VillagerOutdoor`, `Villager._start_outdoor_act` / `_tick_act` / `_tick_chase`). **Umbrella:** in rain one villager at a time takes out their own `npc_def_list` umbrella (`VillagerData.default_umbrella` → `tol_umb_NN`): the NPC control actor lets one claim through per 0.5–1 s window (`umbrella_open_actor` / `umbrella_open_timer`), and the open clears it. `UMB_OPEN1` plays in place while the tool opens (`HeldUmbrella`, same scale tables as the player's), then `UMBRELLA1` drives RARM1, RARM2, HAND and HEAD_ROOT over every other clip (`aNPC_part_tbl1x`, `ToolCarry.build_part`); the head look still lands on top. When the rain stops it folds (`UMB_CLOSE1`) unless the schedule is SLEEP. A villager already outside when the scene loads in rain has it open (`aNPC_check_force_use_umbrella`, `aTOL_ACTION_S_TAKEOUT`). **Clap:** normal mood, within 3 units (6 m) and the player inside ±67.5° of the villager's facing, while the player pulls in / shows / puts away a bug or reels in / shows a fish (`Player.catch_showing` ≈ `PULL_NET` / `NOTICE_NET` / `PUTAWAY_NET`, `FLY_ROD` / `NOTICE_ROD` / `PUTAWAY_ROD`) → `CLAP1` facing the player until it ends. **Chase:** while walking in a normal mood, the nearest fish shadow if one is within 140 GX — any shadow at all means bugs are never checked — else the nearest bug within 100 GX; up to 60 s: bugs run past 120 GX, walk past 80, then face it (turn if > 22.5° off); fish walk past 100, then face. Not ported: the ball (`aNPC_check_ball`, no ball actor), pitfalls (`aNPC_chk_pitfall` → `aNPC_ACT_PITFALL` / `REVIVE`; there are no pitfall seeds yet), the fortune-driven avoid / follow of the player (`aNPC_chk_friendship` only fires with `mPr_DESTINY_POPULAR` / `UNPOPULAR` via `over_friendship`; no fortunes yet), the entrance check, and Able-design umbrellas in their hands.
- **Villagers greeting each other** (`aNPC_greeting_area_check`, `ac_npc_act_greeting.c_inc`; `VillagerGreeting`, `Villager._begin_greeting` / `_tick_greeting`). Each physics frame, wandering outdoor villagers that are free (no partner, 10 s since their last greeting, not angry / sad / sleepy) pair up in actor order within 80 GX (40 GX in height). The first to start rolls one `react_rate_table` reaction (A = the one closer to the player, ties a coin flip): moods ±opinion (`aNPC_set_feel_sub`), catchphrase copied between same-sex villagers (or passed to the first neighbour one acre over whose differs) or reset, an Able umbrella / shirt, a new shop shirt, or back to their own clothes; shirt swaps are off while either wears a present from the player. Opinions go into the relation matrix (0–255). Then both turn, walk in for up to 80 frames until 50 GX apart, bow together (`AISATU1..4` by looks), and whoever's clothes changed plays `GET_CHANGE1` while the other waits; 10 s before either greets again. The around-list sort is the decomp's every-other-slot selection sort. This replaces the old once-a-day stand-in (`NeedleworkTrend.daily_greetings`), so trends now only spread where villagers actually meet. Not drawn: a shop shirt (`cloth_id`) on the model — only Able designs repaint.
- **Shirt presents by mail** (`mNpc_SetPresentCloth`, `mNpc_ChangePresentCloth`, `aQMgr_get_thanks_cloth_msg`): a shirt mailed to a villager who knows you with friendship over 30 goes on at the next game start (`VillagerState.present_cloth` / `wearing_present_cloth`), and their next greeting (after mood greetings) is `MSG_11770` + looks × 3 thanking you for it, once.
- **Tool-hit reaction** (`aNPC_ACT_REACT_TOOL`, `ac_npc_act_react_tool.c_inc`): every net hit makes the villager jump — met or not (`aNPC_check_uzai` returns TRUE on `uzai.flag` before the memory check; only the scold counters need a meeting). Annoyed feel → `gyafun2` and done; player in the look cone → `gyafun2`, then a 5 s stare with the head at talk priority; else `gyafun1`. Head chase rates rise to 0x600 / 0xC00 for the act and the jumps set `SKIP_HEAD_LOOKAT`. Port: `Villager.React` / `_tick_react`, `NpcHeadLook.fast`.
- **In house:** `VillagerState.is_home` mirrors `Animal_c.is_home`. IN_HOUSE outdoors walks to the door (`DOOR_APPROACH`) then hides (`WAKE`). SLEEP while home refuses the door; not-home refuses entry. Awake-home opens the door and spawns an indoor resident (`indoor_resident`) in the NPC room.
- Not on the acre when sleeping or indoors. Walking home/out is still visible.
- **Leaving home is gated on the player's acre.** `aSNMgr_check_move_npc_schedule` only walks a villager whose schedule is FIELD *and* `!is_home`; one still `is_home` has no actor until `aSNMgr_set_npc_regular` spawns it for the player's block, and `aNPC_field_schedule_init_proc` then starts at LEAVE_HOUSE (door opens, walks out). So a villager whose FIELD window began while you were elsewhere stays inside until you enter their acre. New villagers start `is_home` (`m_npc.c`). Port: `Villager.current_activity()` holds a home villager at IN_HOUSE/SLEEP until the player's acre matches their home acre. Not ported: the abstract 7 s block-walk for out-of-acre walkers (the port walks them for real), and the wade-start lookahead (the port uses the player's current acre).
- Looks tables for all six personalities as data. Filbert uses the lazy (boy) table (`data/schedules/pip_weekday.tres`).
- Shared activity runner (`VillagerAI` + reusable `ActivityKind` steps), not per-villager AI scripts or `aNPC_think_*` overlays. Talk is `begin_talk` / `end_talk` on that runner. Wander wait/walk/run weights and acre-center radius are data on `VillagerWalk`. Field walk/run m/s come from the shared `aNPC_spd_data` 1.0 / 3.0 GX rows (`VillagerMotor.RUN_SCALE`), not a per-looks overlay.
- Field goals use `mNpcW_GOAL_*` kinds and acre picks; stay-in-acre then new goal is ~28s (not the original 30-minute arrive counter). Wander dests sit on the 280 GX acre circle (not snapped to a cell); arrive uses √72 GX so a walk covers the rim. Per-frame order matches decomp: move on current facing → BG revise → **circleRangeRevice** (hard clamp to R=280) → reactive avoid → chase turn. Front walls with `avoid_direction == 0` hop ±112.5° / 1 unit via turn-in-place then walk; side commits use `aNPC_avoid_wall` 2 units at 22.5° / 45° / 90° then 180° while still moving. `aNPC_forward_check` probes left/right half-units (not forward): out-of-circle or raised ground ≥20 GX above feet sets `HIT_WALL` / `HIT_WALL_FRONT`. Wander rim picks use FG EMPTY/ITEM1/FTR + `CheckNpc` + circle range.
- Display names use the original villager names; meshes are disc species GLBs (`squ_1`, `cat_1`, …) when converted. Roster data is generated from decomp NPC tables (`tools/build_assets.py --kind villagers --step convert`); catchphrases stay empty except for a few hand-authored ones. The catalog is every GC animal (`NPC_NUM` 236); new towns place six starters (one looks each) — the rest live in the catalog for talk and later move-in. Friendship is an int 0–255 on `Relationship` (`best_friend` at 80), without letter scoring or the villager–villager relation matrix.
- **Move in / move out** (`TownResidents`, `m_npc.c`). The roster is the save's fifteen `animals[]` slots (plus `now_npc_max`, `last_grow_time`, `force_remove_date`, `remove_animal_idx`, `npc_used_tbl`, the 15×15 relation matrix). The world regenerates from its seed, so `WorldGenerator.apply_residents` rebuilds `npc_house_<slot>` on each slot's SIGN plot; plots a house ever stood on stay cleared (`mNpc_DestroyHouse` writes EMPTY). Once per load (`mSDI_StartInit` / `…After`, via `Game._resolve_residents`): `mNpc_SetRemoveAnimalNo` → `mNpc_ForceRemove` → `mNpc_Grow` → `mNpc_SetNpcHome`.
  - **Arrival** (`mNpc_Grow`): only below 15, ≥24 h of clock time since the last arrival (the first check just stamps the time), a `npc_grow_prob[field_rank]` roll (40…100 %; no town rating yet, rank stays 3 → 70 %), and only once the player has met at least `now_npc_max` residents. The looks is the one with fewest residents among looks that still have unseen animals; ties drop the looks of the sex `mNpc_GetMinSex` returns — which is the *more* numerous sex (decomp compares the wrong way; kept). Then a random not-yet-seen, non-islander animal of that looks in NPC-table order (`VillagerData.npc_index`). `npc_used_tbl` resets to today's residents once every animal has lived here. The newcomer takes the first free slot, `moved_in` is set, and a random free SIGN plot (`mNpc_MakeRandTable(n, 30)`; reserves inside an existing house's 3×3 are gone). Their first greeting is the `MSG_11573` table.
  - **Departure** (`mNpc_ForceRemove`): only with all fifteen slots full and ≥10 days since the last arrival/departure. `mNpc_GetGoodbyAnimalIdx` skips `remove_animal_idx` and keeps the animal with fewest memories (0/1 here: met or not), then fewest letter memories, then (land kinds = memories, never decides) the looks the town has most of; any other outcome is a tie drawn at random — including when the candidate's looks is rarer (decomp quirk, kept). The player gets the goodbye letter (mail `0x20E + looks×3 + rand 3`, header/footer from `super`/`ps`) in the mailbox, else at the post office; the animal's memories and state are dropped.
  - Not a move-out: `remove_animal_idx` ("thinking of moving", `aQMgr_check_client_remove`) only matters for the memory-card town transfer (`mNpc_GetRemoveAnimal`); single-card towns never lose that animal to it. The GameCube has no moving boxes.
  - Letter text is on the disc (`mail` / `super` / `ps` + `*z` banks); `--kind dialogue` writes `assets/generated/dialogue/mail.json` and `MailBank` reads it. Stationery is a uniform pick until the shop paper lists exist.
- **After the greeting** (`VillagerTalkManager`, `ac_quest_manager.c` / `ac_quest_talk_init.c` / `ac_quest_talk_normal_init.c`). `DialogueRunner.talk_manager` is asked for the next message whenever one ends on `MSGCONTINUE`; a message ending on `MSGEND` closes the talk (the converter marks the last page `cont` / `open_choice`). It answers the menus it put up. Town residents only (not scripted NPCs, and during the first job only once Nook's "ask around for work" chore is on — `mEv_SAVED_FJOPENQUEST`, which "Need any help?" finishes). Message numbers are `base + looks×3 + rand 3` (`aQMgr_actor_get_my_msg`). `aQMgr_actor_talk_select_talk` picks, in order: a reward owed from last time (AFTER_REWARD), a quest this villager is the target of (finished → FIN_QUEST_START / not-hand contests / letter reply; not yet → errand pick-up or contest reminder), a quest they asked for (reminder, or give-up once the deadline passed), an errand chain they started, a new request while `mNpc_CheckQuestRequest`, else NO_OR_NORMAL (`0x2A6` + "Need any help? / Let's talk! / Never mind" → `0x282`, friendship +1 and a chat topic, or `0x254A`). `mDemo_ORDER_QUEST` orders are only read once the everyday chat has taken over.
- **Chat topics about events** (`aQMgr_decide_msg_ev`). Special visitor (`aQMgr_decide_msg_special_ev`): while `EventCalendar.special_type` is before its start, on its start day, or (Nook's sale) until the sale ends, `l_ev_special + subtype × 3` with the start month / day from the ROM month / day strings (`0x66D` / `0x64E`); the sale's "furniture" string (`0x55D`) stands in for the bargain list's first item. Calendar (`aQMgr_decide_msg_calendar_ev`): a random live rumour at its `event_rumor_table` slot (`l_ev_cal + slot × 2 + rand 2`), the cherry-blossom one only in term 4 and kamakura only in winter, next Sunday's / Saturday's day for the fishing tourneys / fireworks, and the moon dates in FREE16–19. `lb_reki` isn't ported: lunar 8/15 is `EventDates.HARVEST_MOON`, 9/13 is 28 days later, and today's lunar date (the calendar order) counts 29.53-day months from lunar 8/1. Note: `rumor_harvest_festival` currently reads as active into December (its end date decodes before its start), so it can come up then.
- **Catchphrase editor** (`aQMgr_order_change_gobi` → `aQMgr_talk_normal_open_gobi`): the message window goes away and the letter board opens on their current catchphrase (one line, 10 characters, `mLE_TYPE_EPHRASE`); saving sets `VillagerState.catchphrase`, and the message resumes when it closes. Not ported: the remembered town tune (order 6, no town tune yet) and the birthday entry (order 8, no birthday input yet).
- **Quests** (`VillagerQuests`, `m_quest.c`). Deliveries (one per pocket), five errand slots and a contest per resident slot, saved with the player. Quest data is `l_set_delivery_data` / `l_set_errand_data` / `l_set_contest_data` verbatim (target, day limit, steps, hand-over, item source, reward %, max pay, 13 message starts). New request: a turned-down / couldn't-carry offer is re-offered (`npclist.quest_info`, `NpcTalkInfo.client_quest`), else 3-in-4 a random type/kind (first-job tables during the job) that passes `aQMgr_actor_check_occur` (one contest of a kind per town; snowman Dec 25–Feb 17 08–16h; flower Feb 25–Aug with ≥4 empty units and ≤20 flowers by the house; bugs Mar–Nov 28). Foreign / departed-villager deliveries need `stored_anm_id` / `last_removed_animal_id`, which one save never sets, so they never happen. Targets come from `mNpc_GetOtherAnimalPersonalIDOtherBlock` (excluded ids and the asker's acre skipped, the decomp's index walk kept). Accept → the parcel goes into the pocket flagged QUEST and the villager hands it over; decline → friendship −3 (a contest has already started by then). Deadlines: `now + days`, and `mQst_CheckLimitOver` also trips if the clock is set back before the start. The sender takes an overdue parcel back ("dirty thief" and the pockets again until it's handed over, then −5 / −2 / −1 by the failure message). Errand chains: the borrower either hands the item back (FINAL, into your pocket, back to the lender) or says they lent it on (CONTINUE, a new villager, chain stops after the progress runs out); `errand_next` remembers the roll per errand. Hand-over opens the pockets on the quest pocket only (`mSM_IV_OPEN_QUEST`) or any fish / bug for those contests; nothing handed = `0x4AB` and −1. Reward: `aQMgr_actor_set_reward` 100-slot table (errands by chain length), pay scaled by money power ±10 % (money power is always 0 — no feng shui yet), goods from the shop pools (furniture 1-in-10 from the villager's room), the shirt they had on for clothes deliveries (they change into the one you brought, `VillagerState.cloth_id`), bells past the wallet cap as 30,000 bags; pockets full → `give_reward` and paid next time. Friendship +3. Contests count down (`progress`), get three more days and remember the player, then clear on the fin limit or out of season (`aQMgr_actor_regist_quest_move`). Letter contest: the next letter to them (`mQst_SetReceiveLetter`) is ranked by length / quality / present, and they mail back handbill `0x75 + rank×6 + looks` on festive paper with a ranked present. Not ported: the ball and snowman contests can be asked for but not finished (no ball / snowman actors — `mQst_NextSoccer` / `mQst_NextSnowman`), the wishing well that takes stranded quest items (`ac_shrine`), the quest item tag's to/from names, the NPC changing clothes visibly, and the SE jingles. Quest item names are placeholders.
  - **Topic** (`aQMgr_talk_normal_select_talk`): the first ten chats after the first job are its hints (`0x841 + looks×10 + n`, `Private_c.hint_count` → `Game.first_job_hint_count`, with `aQMgr_change_NG_msg`), then a happy villager uses the `l_ki_*` table, anyone else 70 % normal-2 (letter / weather-season small talk / trade / memory) and 30 % "game" (hints, the moving candidate's news, events). Each pick goes through `aQMgr_decide_idx_prob_table` (100-slot table, 30 swaps). Memories and saved letters belong to *other* players, so with one player the memory topic is only the "best friends" line (friendship > 80) and the letter topic only the secret handbill (`0x22 + rand 15`). Special visitors and calendar rumours aren't tracked yet, so those event topics fall back to hints.
  - **Orders** (`aQMgr_talk_normal_demo_order`, slot = type): 0 roof colour, 1 catchphrase editor / re-pick the moving candidate, 2 decide a trade (17 variants: what the villager offers from the shop pools and for how much), 3 run it (23 variants: items and bells move between pockets; over the wallet cap 30,000-bell bags), 4 show the letter, 5 friendship ± (values over 100 are losses), 7 lunar-calendar strings, 9 random words from the string table. Not yet: 6 (memory melody), 8 (birthday entry), the catchphrase editor UI, hand-over animations for trades, `lbRk` lunar conversion.
  - **Mood** comes from the messages too: `mDemo_ORDER_NPC0` slot 2 sets the feel and slot 8 its minutes (`aNPC_set_feel_info`, same feel adds up to 10 min); the timer counts down on the actor (`aNPC_check_feel_tim`) back to normal. Talking no longer makes villagers happy by itself.
  - **Friendship** is the memory's s8 0–127. The first conversation makes the memory at 1 (`mNpc_SetAnimalMemory`); talking adds nothing by itself — "Let's talk!" is +1 and the messages' orders do the rest.
  - **Patience** (`NpcTalkInfo`, `mNpc_Talk_Info_c`, per session): each talk ending within 1000 ticks of the last counts; past the looks' `l_npc_temper` limits the villager is mildly annoyed, then refuses. The reset timer only runs 1000 ticks per acre visit — wading (`Game.notify_wade_start`) re-arms it.
  - **Catchphrases** are the disc defaults (`npc_def_list[].catchphrase_str_idx` → `VillagerData.catchphrase_string`, text from the generated string table), overridden per villager by `VillagerState.catchphrase`.
- **Letters** (`VillagerLetters`, `LetterCheck`, `m_npc.c` / `m_mail_check_ovl.c`). A letter to a resident reaches them when the post office takes it (`mPO_receipt_check_mail` → `mNpc_SendMailtoNpc`): it's kept in the player's memory (making the memory if they'd never met, friendship 0), scored by `mMck_check_key_hit_nes` on the 192-byte body in game character codes (capitalised sentence starts, ending punctuation, three-letter syllable hits from `str_?_table`, spacing, no triple letters, no 75-char run-ons, no 32-char blocks without a space), and friendship moves +3, −5 more for a bad letter (< 50), +3 more with a present. Only a clear verdict (≥ 100 good, < 50 bad) earns a reply. During the first job the letter is kept but moves nothing. The syllable tables are pulled from `foresta.rel` by symbol into `mail_check.json`; the US build lost their 0x7F terminators, so each letter's full scan range into the following data is saved (pointer words there are REL-relocated, not runtime addresses).
  - **Replies** (`mNpc_Remail`, at load after move-in/out): any resident holding a letter from an earlier day writes back — good letters from `superz` / `maila` + `mailb` + `mailc` / `psz` at `this_start_no[looks] + rand` (the body pieces concatenate raw and must fit 192 bytes), half of them with a furniture or clothing present; bad letters get `0xC5 + looks×3 + rand 3`. Free strings: player, villager, another villager and eleven random words from the string table. Mailbox first, else the post office.
  - **Valentine's Day** (`mNpc_SendVtdayMail`, once on Feb 14 at load or the 06:00 renew): each other-sex resident with a memory writes, best friends (≥ 80) first — mail `0x60 + looks×3 + type`, with rare / uncommon furniture or common clothing. With one player the middle "fond, but someone else is the best friend" type never happens.
  - Not yet: birthday cards (the port has no player birthday), present shirts the villager then wears (`mNpc_SetPresentCloth`, friendship > 30), letters to villagers in other towns, shop-list stationery.
